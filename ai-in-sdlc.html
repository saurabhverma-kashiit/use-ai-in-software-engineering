Using AI in the Software Development Life Cycle (SDLC)

This page captures my practical learnings on how AI can be applied across the Software Development Life Cycle (SDLC). Rather than replacing engineers, AI acts as a force multiplier—helping us plan better, code faster, test smarter, and operate systems more efficiently.

The goal here is to document how an experienced engineer can realistically use AI tools in day-to-day work, based on hands-on exploration.

1. Planning & Requirements

Planning is often ambiguous and time-consuming. AI can help convert raw ideas into structured artefacts quickly, reducing back-and-forth and missed requirements.

What AI Helps With

  • Converting ideas into Epics → Features → User Stories
  • Generating acceptance criteria
  • Identifying missing scenarios and edge cases

Example Prompt

Act as a product owner. Convert the following idea into epics, features, user stories, and acceptance criteria: <describe idea>
Why it matters: Faster clarity, better alignment, and fewer requirement gaps early in the SDLC.

2. Architecture & Design

Architecture decisions benefit greatly from AI-assisted brainstorming, especially when evaluating trade-offs.

What AI Helps With

  • High-level system design suggestions
  • Generating architecture diagrams (C4, flow diagrams)
  • Identifying risks, bottlenecks, and scalability concerns

Example Prompt

Design a scalable architecture for a system with the following constraints. Explain trade-offs and potential risks.
Tip: Always validate AI-generated designs with real constraints, load expectations, and security requirements.

3. Implementation (The Shift-Left)

During coding, AI acts like a pair programmer—not perfect, but incredibly useful when guided correctly.

What AI Helps With

  • Code scaffolding and boilerplate generation
  • Refactoring suggestions
  • Explaining unfamiliar codebases
  • Generating documentation and comments

Example Prompt

Refactor this code to follow SOLID principles and improve readability. Explain the changes.
Rule of thumb: Use AI to accelerate thinking—not to skip understanding.

4. Testing & Integration

Testing is one of the most impactful areas where AI saves time while improving quality.

What AI Helps With

  • Unit and integration test generation
  • Edge-case discovery
  • Test data generation
  • Playwright / API test scaffolding

Example Prompt

Generate unit and integration test cases for this service, including edge cases.
Impact: Better test coverage with less manual effort.

5. Operations & Maintenance

AI continues to add value even after deployment by improving observability and incident response.

What AI Helps With

  • Log analysis and error summarization
  • Root cause analysis
  • Runbook generation
  • Performance tuning suggestions

Example Prompt

Analyze these logs and summarize the issue, possible root causes, and mitigation steps.

Summary & Key Takeaways

  • AI enhances every phase of SDLC, not just coding
  • The biggest value comes from experienced engineers guiding AI
  • AI reduces friction, not responsibility
  • Critical thinking and validation remain essential
