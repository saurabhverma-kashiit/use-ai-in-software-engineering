AI-Augmented SDLC Framework

Operational guide for Architecture, Agile, DevOps, and Maintenance workflows using GitHub Copilot, Gemini, and Cursor.

1. Planning & Requirements

Gemini • Jira Plugins

Idea to Epic

  • Brainstorming: Use AI to structure raw ideas into Epics > Features > Stories hierarchy.
  • Acceptance Criteria (AC): Generate exhaustive ACs, including edge cases and negative scenarios.
  • Dependency Mapping: Ask AI to analyze a list of stories and identify logical blockers/sequences.

Analysis (SRS & Agile)

  • "Just-in-Time" Requirements: In Agile, generate detailed specs only for the upcoming sprint to reduce waste.
  • Gap Analysis: Feed AI the SRS and ask: "What assumes a happy path? Where will this break?"
  • Compliance Check: "Review these requirements for GDPR and PCI-DSS compliance risks."

2. Architecture & Design

Mermaid.js • TOGAF • STRIDE

Modeling (C4 & BDAT)

  • Visuals as Code: Generate Mermaid.js or PlantUML code for C4 Container diagrams.
  • TOGAF Alignment: Validate design decisions against enterprise modularity principles.
  • Integration Strategy: "Compare Webhooks vs Polling for this specific data flow."

Risk & Security

  • AI Threat Modeling: Paste the architecture and prompt:
    "Analyze this design using the STRIDE methodology. Identify potential spoofing or elevation of privilege risks."
  • Single Point of Failure: Ask AI to stress-test the design for bottlenecks.

3. Implementation (The "Shift Left")

Cursor • Copilot • GitHub Actions

Context Engineering

  • .cursorrules / Agent.md:
    💡 Pro Tip: Create a .cursorrules file in your root. Define your Tech Stack, Folder Structure, and Patterns (e.g., "Always use Repository Pattern"). AI tools read this first!
  • Prototype/MVP: Generate full microservice skeletons to "Fail Fast" and validate concepts.

Code Quality

  • Pre-PR Review: "Review my changes for Clean Architecture violations and potential memory leaks before I commit."
  • Documentation: Auto-generate Architecture Decision Records (ADRs) from conversation transcripts.
  • Refactoring: Use Cursor (Cmd+K) to extract complex logic into reusable services.

4. Testing & Integration

Playwright • NUnit • Postman

Test Generation

  • AC to Test Cases: Convert User Stories directly into Gherkin (Cucumber) syntax or NUnit test classes.
  • Smart Stubs: "Create a mock Payment Gateway that randomly simulates timeouts to test our retry logic."

Coverage & Automation

  • Property-Based Testing: Ask AI to generate random inputs (Fuzz Testing) to break your validation logic.
  • Integration Scripts: Generate Playwright/Selenium automation scripts directly from the UI design mockups.

5. Operations & Maintenance

Gemini • Datadog AI • SQL

Observability & RCA

  • Log Analysis: Paste obscure error logs or stack traces into Gemini:
    "Explain this Java stack trace in plain English and point to the likely root cause."
  • Incident Summaries: Feed the incident chat history (Slack/Teams) to AI to auto-generate the Post-Mortem / RCA Report.

Legacy Modernization

  • Code Archaeology: Highlight undocumented legacy functions and ask: "Explain the business logic of this function step-by-step."
  • Performance Tuning: "Analyze this SQL query. Suggest indexes or rewriting strategies to optimize execution time."
  • Dependency Upgrades: "List the breaking changes I need to handle when migrating from Angular 14 to 17."
